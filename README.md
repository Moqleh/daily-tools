# أدواتك اليومية | Daily Tools

منصة عربية/إنجليزية تجمع أدوات يومية عملية في مكان واحد، بتصميم سريع ومتجاوب يعمل على الهاتف والكمبيوتر.

## التقنية
- React 19 + TypeScript
- Vite
- Lucide Icons
- CSS responsive
- أدوات أساسية تعمل محليًا في المتصفح

## التشغيل محليًا
```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج
```bash
npm run build
```

## مبادئ المشروع
- عربي / English مع RTL وLTR
- لا يحتاج المستخدم إلى تسجيل للأدوات الأساسية
- تجنب الاعتماد على APIs مدفوعة أو مفاتيح خارجية للأدوات الأساسية
- الخصوصية أولًا والمعالجة المحلية متى كانت عملية
- الخدمات الخارجية، عند ذكرها، مستقلة وتخضع لشروط وسياسات أصحابها
- النتائج الصحية والمالية التقديرية للمعلومات العامة ولا تستبدل المختص أو المصدر الرسمي
